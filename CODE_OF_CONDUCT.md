# Community conduct

Everyone contributing through issues, pull requests, reviews, or project discussions is expected to:

- Be respectful and welcoming across backgrounds and experience levels.
- Give specific, constructive feedback about the work.
- Respect privacy and use only approved public contact information.
- Avoid harassment, discrimination, threats, sexualized content, personal attacks, and spam.
- Credit others' work and respect media permissions.

Maintainers may edit or remove disruptive content and restrict participation when needed to keep the project constructive. Concerns should be raised privately with the repository maintainer through an available private channel; do not post sensitive reports in public issues. If no private route is available, ask for one without including sensitive details.
